\heading{Overview of the pipeline}
The pipeline takes a source turtle program and a set of safety properties as input. Using Chiron's API, the program is translated to Chiron-IR and its relevant user and state variables are extracted. The program semantics are then encoded as Constrained Horn Clauses (CHCs), and combined with the properties expressed in CHC form. This CHC system is given to \texttt{Z3}'s \texttt{SPACER} engine, which checks whether an \textbf{unsafe} state is reachable. A \texttt{sat} result yields a concrete counterexample, while \texttt{unsat} proves that the property holds.
